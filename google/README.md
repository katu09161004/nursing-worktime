# Google スプレッドシート連携（集計の自動取得）

サーバの集計を Google スプレッドシートへ自動で取り込む。CSVをダウンロードして
開き直す往復がなくなり、URLを共有すれば常に最新の集計を全員が見られる。

**記録（打刻）はこの仕組みでは行わない。** 打刻は従来どおり記録画面（Webアプリ）で、
手入力はExcelで行い、このシートは**集計を見るため**に使う。

## できること

| シート | 内容 |
|---|---|
| 設定 | 期間・病棟・勤務帯の絞り込み。空欄なら全件 |
| サマリ | 総記録時間・勤務時間内/外・延べ勤務数・1勤務あたり |
| 集計_大分類 / 中分類 / 小分類 | 分類ごとの合計・割合 |
| AIベースライン | `ai_tool` を設定した小区分だけ抽出（AI導入前後の比較用） |
| 明細 | `/api/export.csv` の生データ。`データ元` 列で Web打刻 と Excel を区別できる |

## 導入手順

1. 新しいスプレッドシートを作る
2. **拡張機能 → Apps Script** を開き、既定の `コード.gs` の中身を消して
   [`nwt-sheets.gs`](nwt-sheets.gs) の内容を貼り付け、保存する
3. スプレッドシートに戻って**リロード**する（メニュー「業務量調査」が出る）
4. **業務量調査 → 初期セットアップ（シート作成）**
5. **業務量調査 → APIキーを登録**
   - Excelの入力シート **N7 と同じ値**を貼り付ける
   - キーはスクリプトプロパティに入るので、シートを共有しても閲覧者には見えない
6. **業務量調査 → 今すぐ更新**
7. 自動更新するなら **業務量調査 → 自動更新をONにする**（既定6時間ごと。
   `NWT_REFRESH_HOURS` で変更可）

初回実行時に Google の認可画面が出る。「このアプリは確認されていません」と表示されたら
**詳細 → （プロジェクト名）に移動** で続行する（自分で書いたスクリプトなので想定どおり）。

## 接続先

`nwt-sheets.gs` 冒頭の `NWT_BASE` にサーバのURLを書く。既定はVPS。

```javascript
const NWT_BASE = 'https://ik1-106-59985.vs.sakura.ne.jp/nwt';
```

**院内DL380には接続できない。** Apps Script は Google のサーバー上で動くため、
院内LANの私有IPには到達できない。DL380のデータは
[`deploy/sync_export.py`](../deploy/sync_export.py) →
[`deploy/sync_import.py`](../deploy/sync_import.py) でVPSへ寄せてから見ること。

## 注意

- APIキーを持てば集計を読めるので、**シートの共有範囲＝データの公開範囲**になる。
  施設ドメインのアカウントで作り、共有は必要な人だけにすること
- 記録内容は業務区分と時刻のみで患者情報は含まないが、外部クラウドに置く判断は
  施設のポリシーに従うこと
- 401 が返る場合はAPIキーが違う。サーバ側で `config_local.py` の `AUTH["api_key"]` を
  変更した場合は、このシートとExcelの両方を更新する必要がある
