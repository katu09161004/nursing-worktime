Nursing Workload Logger

看護業務量調査ツール

看護業務にかかる時間を 「ボタン1タップ」 で記録し、 AI（音声記録・退院時サマリー・議事録）導入の前後で効果を測る基準値を集めるための、 オンプレ完結・PHIを扱わないツールです。

📖 使い方マニュアル ▶ 記録画面をさわる（デモ） 集計ダッシュボード（デモ）
※デモはブラウザ内だけで動作します。サーバ送信・保存はされません。

何をするツールか

看護師は「今やっている業務」のボタンを押すだけ。次のタップまでの時間が、その業務の 所要時間として自動で記録されます。「開始／終了」の2度押しは不要。集めたデータは、 AI導入前後の比較ベースラインと多職種協働加算のエビデンスの両方に使えます。

目的直結

AIベースライン自動集計

SOAP入力・サマリー・カンファレンスを対象区分として分離し「分／シフト」で表示。

安全

PHIを扱わない

記録するのは業務区分と時刻だけ。担当者は匿名ID。患者情報は一切入力しない設計。

自己完結

オンプレ／外部通信なし

FastAPI + SQLite。院内サーバ1台で完結。データは1ファイルでバックアップ可。

運用性

モバイル＆常駐化

ブラウザで開くだけ、ホーム画面追加でアプリ風。systemdで常駐。

AI効果測定への使い方

導入前に2〜4週間記録し、対象業務の「分／シフト」を確定（＝ベースライン）。

導入後、同じ期間・病棟・勤務帯で再度記録。

2つの「分／シフト」の差分＝削減時間。のべ勤務数と人件費を掛ければ金額換算まで一直線。 同じ1回の調査で「効果測定」と「加算エビデンス」の両方を賄えます。

使い方（看護師）

  1. ブラウザで記録画面を開く（ホーム画面に追加しておくと便利）。
  2. 最初に担当者・病棟・勤務帯を選ぶ（初回だけ）。
  3. 業務を始めるたびに、その区分ボタンを1タップ。
  4. 勤務の終わりに「記録終了」。押し間違いは「直前を取り消す」。
